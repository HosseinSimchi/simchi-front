###### Single Object Detection

- ###### Object -- منظور شی است که در تصویر قرار گرفته است
- ###### Predict the Label in Object Detection
- ###### Localization -- یافتن محل قرارگیری آبجکت در تصویر
- ###### Bounding Box (BB) -- مختصات محل قرارگیری شی رو به ما میده
  - ##### Given four points -- (x,y) : Starting Point - h (height) and w (width)
- ###### The model should predict two values
- ###### 1- BB -- (x,y,w,h)
- ###### 2- Label
- ###### The structure of the model 👉 Should have two `outputs` (Object detection and Localization Bounding Box)
- ###### Train image Dataset
  - ###### Targets
    - ###### annotations (اطلاعات مرتبط با آبجکت هارو به ما میده) --> BB
    - ###### Labels
- ###### Loss -- باید خظارو در سمت لیبل کاهش دهیم و طوری مدل را اموزش دهیم که بتونه مختصات آبجکت ها در تصویر رو به ما بده
- ###### For Label Predictions -- We are working on `Classification` and also we use `Softmax`
- ###### For Bounding Box Predictions -- We are workign on `Regression` (Because of using Continuous numbers).
- ###### Image --> Convolutions (To extract features) --> The first output (Dense + Softmax) To predict Label and The second output (Dense) To predict BB
- ###### The first output LOSS --> L1 and The second output LOSS --> L2
  - ###### Total Loss = L1 + L2
- ###### WE can display the Label and BB on the image using `OpenCV` or other tools
- ###### Dataset and annotation (bounding_box.ipynb)
- ###### `STRUCTURE- ` dataset/images/ (We have 3 folders for each class) + dataset/annotations/ (We have 3 .csv files for each class)
  - ###### Class Label -- نام هر فولدر
  - ###### BB -- محل قرارگیری هر شی داخل اون تصویر
  - ###### annotations.csv --> نام هر تصویر داخل این فایل توشته شده به همراه ۴ تا عدد که مختصات اون شی رو به ما میده. کافیه این نام رو داخل فولدر تصویرش پیدا کنیم و تصویر متناظرش رو بخونیم
  - ###### Draw BB on the image
  - ###### معمولا نیاز داریم تا تصویر ریسایز رو کنیم و بعد به شبکه بدهیم. در این حالت سایرهای باندینگ باکس ما دیگه معتبر نیست
    - ###### راه حل ما در این شبکه نگاه کردن نسبی به باندینگ باکس است بدین معنا که باید ببینیم عرض و طول این باندینگ باکس ما چند درصد تصویر رو گرفته
    - ###### برای چهارتا نقطه باید اینکار رو بکنیم
    - ###### `h,w,_ = img.shape`, `ann[0] = ann[0]/w`, `ann[1] = ann[1]/h`, `ann[2] = ann[2]/w`, `ann[3] = ann[3]/h`
      - ###### `ann[0]: عرض باندینگ باکس`
    - ###### کافی است سایز تصویر ریسایز رو شده در تمامی ابعاد مظابق فوق ضرب کنیم تا نقاط باندینگ باکس جدید بدست بیاد
      - ###### `ann[0] = int(ann[0] * 224)` and so on
      - ###### چون مقادیر فلوت برای تصاویر نداریم مقادیر بدست اومده رو به اینتیجر تبدیل میکنیم
- ###### How to solve the problem (Object detection and Localization)
- ###### 1- The input of the model is `image`
- ###### 2- The output of the model is --> Classification (To predict the label of the detected object) and Regression (To predict the localization)
- ###### 3- The Model has one input and two outputs
  - ###### So, we use `functional API`
- ###### 4- we should ectract and store these items --> imgae, classification lebels and regression lebels
- ###### 5- At the classification part --> It's used `softmax` activation function
- ###### 6- At the regression part --> It's used `sigmoid` activation function (To predict continuous values between ZERO and ONE) -- If yuo need to predict the actual value for BB, you should use `linear` AF to predict the BB values. sigmoid is a great choice to cilp the output model
  - ###### مقادیر باندینگ باکس ما بین صفر و یک قرار دارند زیرا که با تقسیم بر سایز تصویر اونارو به صورت نسبتی دراوردیم و باید درنظر داشته باشیم که برای این حال تابع فعال ساز سیگموید بهترین گزینه است
- ###### 7- To define Loss functions for classification, `Cross-Entropy` is used and also for the Regression, `MSE` is used. (YOU can use dictionary to define diffrenet loss functions)

    - ###### Fast R-CNN

      - ###### Introduced to resolve the problems of R-CNN
        - ###### The problem of R-CNN
          - ###### CNN -- باید به تعداد هر ریجن پروپوزال باید یکبار این قسمت اجرا میشد که سرعت بشدت کاهش میابد
        - ###### در این روش فقط یکبار تصویر رو از شبکه عبور میده
      - ###### هزینه محاسباتی رو تا حد زیادی کاهش میده
      - ###### Image --> Selective Search (As similar to R-CNN) --> Get all region proposal
      - ###### `NEW-` Image --> CNN --> Get features from net (features map)
      - ###### `NEW-` ROI --> The features From CNN and Region Proposal from the Selective Search --> `ROI Pooling Layer`
      - ###### `ROI Pooling Layer`
        - ###### دقت کنید برای هر تصویر فقط یکبار فیچرهارو بدست میاریم
        - ###### به ازای هر ریجنی که بدست میاد از هر تصویر مختصات قرارگیری اون ریجن رو باید در فیچرمپی که داریم بدست بیاریم
      - ###### Feature Map -- Suppose that the size of image: (256, 8, 8)
        - ###### بدین معنا است که هر کدام از فیچرمپ ها به یک ویژگی اشاره میکنند. یعنی مثلا یکی بیانگر لبه ها است و الی آخر.
        - ###### From (256,256,3) : Image size --> To (256,8,8) --> 8,8 : وقتی از ابعاد ۲۵۶ در ۲۵۶ به این ابعاد رسیدیم بدین معنا است که تقریبا با یک نسبتی تصویر ما کوچکتر شده ولی محل قرارگیری پیکسل ها تقریبا ثابت است (فاصله مکانی )
          - ###### تقریبا شبیه این است که تصویر با یک درصدی کوچکتر میشه.
        - ###### Ex./ Image size = (240, 240, 3) and Feature_Map size = (20,20,256) --> Scale_factor = 20/240 = 1/12 --> بدین معنا که انگار هر پیکسل ما در تصویر اولیه داخل فیچرمپ به اندازه ۱/۱۲ جا به جا شده.
      - ###### وقتی میخواهیم پروپوزال ریجن رو داخل فیچرمپ سرچ کنیم یعنی باید ببینیم در تمامی فیچرمپ هایی که بدست اومده آیا همچنان آبجکت پیدا شده قابل مشاهده است یا خیر یعنی مثلا اگر در تصویر اولیه یک توپ پیدا شده در داخل فیچرمپ هم بدست آمده یا خیر.
      - ###### Why ROI + Pooling Layer --> وقتی که نواحی رو داخل فیچرمپ پیدا میکنه این نواحی بدست آمده دارای سایزهای متفاوتی هستند فلذا باید یکسان سازی روی نواحی بدست آمده انجام دهد به همین دلیل به آن لایه ی پولینگ میگویند. بعد از یکسان سازی اونو به لایه فلتن میده و در ادامه در اخبتیار قسمت های دنس قرار داده میشه
      - ###### Problems
        - ###### Selective Search is Bottleneck --> همچنان مشکل زمانی در این قسمت داریم
        - ###### Scale Factor --> اگر عدد اعشاری بدست بیاد برای اینکه داخل فیچر مپ بتونیم سرچ کنیم باید این رو رند کنیم که بر اثر همین عملیات یکسری خطا در شبکه به وجود می آید
          - ###### پس یک خطای سیستمی داخل این لگوریتم داریم
      - ###### It's a supervised algorithm --> What is the Label/annotations?
        - ###### در این الگوریتم وقتی ریجن ها بدست میان باید با لیبل های واقعی مقایسه انجام بدیم
        - ###### We evaluate each region using IOU (Upper than 0.5 value) --> اگر مقدار بالای 0.5 بدست بیاد میگیم این همون لیبل رو داره ولی اگر کمتر باشه لیبل دیگری را به آن اختصاص میدهیم مثلا لیبل بک گراند رو بهش میدیم

- ###### Object Detection
  - ###### Classification
    - ###### Look at the maximum propablity
      - ###### If you need to classify three classes and the final input is : [0.4, 0.3, 0.3] - the model choose the first class because it has the maximum propability
      - ###### میتونیم یک ترشلد نیز درنظر بگیریم که مثلا بگیریم مقدار ترشلد ما ۰/۶ میباشد
      - ###### مثلا اگر درصد احتمال بدست آمده (بالاترین احتمال ) بالاتر از مقدار ترشلد هست همون کلاس رو بهش نسبت بدیم وگرنه مثلا بگیم نمیدونیم لیبل اون کلاس چیه
  - ###### BB
    - ###### چه متریکی رو میتونیم برای مقایسه باندینگ باکس پیش بینی شده و واقعی درنظر بگیریم
    - ###### IOU (Intersection Over Union)
      - ###### اشتراک دو ناحیه ی واقعی و پیش بینی شده رو بدست بیار و این مقدار اشتراک رو بر مقدار اجتماع این دوناحیه تقسیم کن
      - ###### IOU = 0 --> بذترین حالت ممکن
      - ###### IOU = 1 --> بهترین حالت ممکن و برابر است با اورلپ کامل
      - ###### IOU > 0.5 --> باکس هایی است که مورد قابل قبول است
    - ###### Difference between TP, FP, FN
      - ###### TP
        - ###### IOU > Threshold and Label_predicted = Label_Ground_Truth -- هردوتاش درست باشند
      - ###### FP
        - ###### IOU, Label --> اگر یکی از آن ها درست نباشد این حالت اتفاق می افتد
      - ###### FN
        - ###### اگر آبجکت در تصویر داشته باشیم ولی هیچ شناسایی انجام نشده باشد این حالت اتفاق می افتد
      - ###### برای تمامی آبجکت های درورن تصویر این سه حالت فوق رو جداگانه بدست میاریم مثلا برای 5 تا آبجکت در دسته اول قرار میگیرند و 3 تا ابجکت در دسته دوم قرار میگیرند و 1 ابجکت هم کلا شناسایی نشده داریم که در دسته سوم قرار میگیرد
    - ###### Precision -- آبجکت هایی که در تصویر شناسایی نشدند رو اصلا توی فرمولش حساب نمیکنه (دسته سوم)
    - ###### Recall -- میاد بررسی میکنه که از تعدادی که باید تشخیص میدادیم چه تعدادی رو اصلا تشخیص ندادیم
    - ###### THE BEST GOAL --> Need to have `high` precision and recall --> We have different SCORE for those metrics based on the `Threshold`.
      - ###### Changing threshold can cause lower precision and higher recall ro higher precision and lower recall. (Trade-off between precision and recall)
      - ###### PR-Curve
        - ###### میتونیم به ازای ترشلدهای متفاوت مقدار پرسیژن و ریکال مختلفی رو بدست بیاریم و اونو رسیم کنیم
        - ###### محور عمودی بیانگر مقدار پرسیژن و محور افقی بیانگر مقدار ریکال هست
        - ###### (1,1) --> بهترین حالت ممکن هست که هر دو معیار مقدار کامل رو دارند
        - ###### Average Precision (AP) --> انتگرال زیر سطح نمودار هست
        - ###### Multi Object --> مقدار میانگین پرسیژن که برای هر آبجکت بدست میاریم متفاوت هست
          - ###### Mean Average Precision --> میانگین مقدار بدست آمده برای تمامی آبجکت ها است
        - ###### میتونیم با بررسی این نمودار یک مقدار بهینه برای ترشلد بدست بیاریم
